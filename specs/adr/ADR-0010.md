# ADR-0010: Canonical Unicode Form — Saltillo = U+02BC

- **Status:** accepted
- **Date:** 2026-06-10
- **Authority:** Engineering + Lineage (orthographic standard per Stanzione)
- **Supersedes:** —

## Context

K'iche' Maya orthography uses a glottal stop marker — the saltillo — that appears in
virtually every core term in the tradition: Kʼicheʼ, Ajqʼij, Popol Wuj's Tzʼakol
Bʼitol, the nahuales (Kʼat, Kʼawoq, Ajpuʼ), and throughout the corpus. This
character can be encoded in Unicode as:

- U+0027 — APOSTROPHE (ASCII straight quote, keyboard default)
- U+2019 — RIGHT SINGLE QUOTATION MARK (typographic "smart quote")
- U+02BC — MODIFIER LETTER APOSTROPHE (the linguistically correct glottal marker)

These three codepoints are visually near-identical in most fonts. They are
computationally distinct: a corpus stored in one form and queried in another produces
silent retrieval failure — no match, no error, no warning. The system goes vague;
no one knows why.

This is not a theoretical risk. The project's own deployment history includes
shell-quoting conflicts with K'iche' apostrophes that caused real debugging time.
The v3 audit identified Unicode normalization as a gremlin in Territory 3.

## Decision

The canonical encoding for the K'iche' saltillo throughout THE ELDER is **U+02BC
(MODIFIER LETTER APOSTROPHE)**. All corpus text and all query text must be in this
form before any storage or lookup operation.

This is enforced by `normalize.ts` (`normalizeKiche()` function), which must be called
at two mandatory chokepoints:
1. **Corpus ingestion** — in `ingest.py`, before any passage is stored or embedded
2. **Query time** — before any retrieval query is executed

The `assertCanonical()` function in `normalize.ts` may be used as a hard guard in
tests and ingestion scripts; it throws if non-canonical text is passed.

All ingestion scripts must use the heredoc pattern (`python3 << 'EOF'`) — never
`python3 -c` with shell-interpolated K'iche' text, which breaks on zsh.

## Consequences

- No corpus file, prompt file, or query path may skip the normalization gate.
- The CI test suite includes normalization gate invariants (tests/resilience.test.ts,
  lines asserting that all three forms collapse to U+02BC).
- The `schema.sql` `body_normalized` boolean column is proof-of-gate: only rows where
  normalization ran are marked TRUE; the `retrievable_passage` view requires TRUE.
- New contributors must be told about this rule before they touch corpus files —
  it is easy to introduce non-canonical text by pasting from a word processor
  or a browser without noticing.

## Provenance

Emerged from deployment debugging history (shell-quoting incidents with K'iche' terms).
Formalized in the v3 unknown-unknowns audit. Implemented in `normalize.ts`, committed
to `main` on 10 June 2026.
