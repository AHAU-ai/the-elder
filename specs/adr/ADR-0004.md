# ADR-0004: Calendar Anchor — 22 April 2020 = 5 Kawoq

- **Status:** accepted
- **Date:** 2026-06-10
- **Authority:** Lineage — Dr. Vincent James Stanzione (verified)
- **Supersedes:** —

## Context

The Chol Q'ij is a continuously running 260-day cycle. To compute any Gregorian
date's nahual and trecena number, the engine needs a verified anchor point — a
Gregorian date whose Chol Q'ij equivalent is known with lineage certainty, not
derived from secondary or internet sources.

Multiple anchor points circulate in published and online material, not all of which
agree, and some of which reflect regional or lineage variations. Using an unverified
anchor silently propagates error across every Cruz Maya calculation, every Venus phase
determination, and every session that touches the calendar — with no error thrown and
no warning to the seeker.

## Decision

The canonical anchor is: **22 April 2020 = 5 Kawoq (5 Kawuq)**.

This anchor is lineage-verified by Dr. Stanzione and is the only anchor the calendar
engine may use. All date arithmetic in the engine — nahual, trecena, Cruz Maya
positions, Lords of the Night — derives from this single point.

## Consequences

- The golden test suite must include this anchor as an identity assertion:
  `computeNahual(new Date("2020-04-22"))` must return `{ nahual: "Kawuq", number: 5 }`.
- Any proposed change to the anchor requires a new ADR and Dr. Stanzione's explicit
  sign-off; it is not an engineering decision.
- The anchor date must be stored as a constant in the calendar engine source, with a
  comment citing this ADR by number, so no future session can treat it as an arbitrary
  magic number.
- Day-boundary semantics (what time of day the Chol Q'ij day turns) are governed by
  ADR-0011, which is currently OPEN pending Ajq'ij review. Until ADR-0011 is accepted,
  the engine must fail-toward-silence for birth times within two hours of any midnight
  boundary rather than silently assigning an incorrect nahual.

## Provenance

Verified by Dr. Stanzione during calendar engine development. Treated as the
foundational invariant of the Chol Q'ij engine throughout all architecture sessions.
Referenced in all three strategy document revisions.
