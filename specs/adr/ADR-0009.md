# ADR-0009: Fail-Toward-Silence as the Universal Failure Outcome — Constitutional Rule

- **Status:** accepted
- **Date:** 2026-06-10
- **Authority:** Constitutional — v3 Unknown-Unknowns Audit, Founders
- **Supersedes:** —

## Context

A foundation model under failure — empty context, broken retrieval, timeout, contract
violation, corpus uncertainty — tends to confabulate: to generate plausible-sounding
text that has no grounding in the material it is supposed to draw from. For most
applications, confabulation under failure is an annoying bug. For THE ELDER, it is
the deepest possible betrayal: the instrument misrepresenting a tradition at exactly
the moment when no one is watching, because the failure is invisible to the seeker.

The v3 audit identified this as one of two principles that must be constitutional
rather than advisory — written into the generation contract, tested with broken-input
golden tests, and enforced across every failure path without exception.

## Decision

**Every failure path in THE ELDER resolves to the voice saying less — declining,
deferring, or going quiet in register — never to confident generation from an
uncertain or empty base.**

This is implemented as:
1. The terminal clause of every generation contract (voice prompt): explicit
   instruction to mark uncertainty and decline rather than invent.
2. The `failTowardSilence.ts` module: every failure class has a defined in-register
   utterance; the `guardReading()` wrapper catches all thrown errors and resolves
   them to silence.
3. Broken-input golden tests: the test suite includes deliberately broken inputs
   (empty retrieval, normalization mismatch, timeout simulation) and asserts that
   the output is a silence utterance, never a confabulated Reading.

The six failure classes and their in-register silences are defined in
`failTowardSilence.ts`. The safety intercept class (`safety_intercept`) additionally
exits ceremonial register entirely and provides referral language.

## Consequences

- No prompt revision may remove the fail-toward-silence terminal clause without
  superseding this ADR.
- The broken-input golden tests run on every commit via CI; a failure here blocks
  the build.
- This rule applies to ALL voices equally, including the Keeper of the Fire fallback.
- "Saying less" is in character: an Ajq'ij who does not know does not pretend to know.
  The silence utterances in `failTowardSilence.ts` are written to honor this — they
  are the voice behaving correctly, not the system apologizing.
- This ADR is the authority behind the architectural principle stated in the v3
  strategy document closing: "When the system does not know, it says less. When the
  tradition has not spoken, the code does not answer."
