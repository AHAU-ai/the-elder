# ADR-0003: Imox-First Nahual Ordering

- **Status:** accepted
- **Date:** 2026-06-10
- **Authority:** Lineage — Dr. Vincent James Stanzione
- **Supersedes:** —

## Context

The 20 nahuales of the Chol Q'ij can be ordered from different starting points
depending on tradition, region, and source. The most widely circulated internet
renderings use Imix (the Yucatec/Yucatán spelling) as the first day, but the ordering,
spelling, and lineage verification vary significantly across sources. THE ELDER's
calendar engine must use a single authoritative ordering, and that ordering must be
lineage-verified rather than derived from undifferentiated secondary sources — the
precise failure mode the corpus-grounding architecture is designed to prevent.

## Decision

The Chol Q'ij nahual sequence begins with Imox. This is the K'iche' orthography and
ordering as confirmed by Dr. Stanzione's lineage research and his translation of the
Ximénez transcription. The sequence is:

Imox, Iq', Aq'ab'al, K'at, Kan, Keme, Kej, Q'anil, Toj, Tz'i', B'atz', E, Aj, Ix,
Tz'ikin, Ajmaq, No'j, Tijax, Kawuq, Ajpu

This ordering is the only sanctioned sequence for the calendar engine, all UI display,
all voice prompts, and all corpus metadata `nahuales` fields.

## Consequences

- The calendar engine must be initialized against this sequence and the golden test
  suite must assert it.
- Any source (academic paper, external library, user input) that presents a different
  ordering is treated as requiring review before adoption; this ADR is not superseded
  by convenience or majority usage.
- The K'iche' orthography (not Yucatec/colonial spellings) is canonical throughout.
  "Tzolk'in" is not used; "Chol Q'ij" is the only sanctioned name for the 260-day
  sacred calendar.
