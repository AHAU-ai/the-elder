# ADR-0008: Cruz Maya Five-Position Mapping

- **Status:** accepted
- **Date:** 2026-06-10
- **Authority:** Lineage — Dr. Vincent James Stanzione
- **Supersedes:** —

## Context

The Cruz Maya (Mayan Cross) is a divinatory structure that reads five positions
derived from a seeker's birth nahual, producing a multi-dimensional portrait of
their mythic inheritance. Different sources present different offset values and
directional assignments for these positions. As with the calendar anchor (ADR-0004),
the mapping must be lineage-verified rather than derived from secondary sources,
because errors in the offsets silently assign wrong nahuales to wrong positions —
a compounded error that no individual calculation check would catch.

## Decision

The Cruz Maya maps five positions using the following lineage-verified offsets from
the birth nahual (Center):

| Position | Direction | Offset |
|----------|-----------|--------|
| Center   | —         | 0 (birth nahual) |
| Origin   | TOP       | −8 days |
| Destiny  | BOTTOM    | +8 days |
| Paternal | LEFT      | −6 days |
| Maternal | RIGHT     | +6 days |

A sixth dimension — Venus phase at birth (Morning Star = Pioneer, Evening Star =
Warrior) — is fixed at birth and does not shift with the Cruz positions. It is
treated as an additional layer, not a sixth Cruz position.

Offset arithmetic wraps within the 20-nahual cycle (mod 20); the trecena number
is computed independently for each position.

## Consequences

- The calendar engine must implement these exact offsets. Any change requires a
  new ADR with Dr. Stanzione's explicit sign-off.
- The golden test suite must include at least three Cruz Maya computations against
  known birth dates with verified outputs.
- Venus phase computation is governed separately; its conjunction-case behavior
  is an open question (ADR-0012, currently OPEN) and the engine must
  fail-toward-silence for conjunction birth dates until ADR-0012 is resolved.
- UI and voice prompts must use the directional labels (TOP/Origin, BOTTOM/Destiny,
  LEFT/Paternal, RIGHT/Maternal) consistently; no alternate naming without a
  superseding ADR.

## Provenance

Defined during Cruz Maya implementation sessions. Offsets verified by Dr. Stanzione.
The sixth Venus dimension was added in a subsequent session and treated as a standing
part of the architecture from that point forward.
