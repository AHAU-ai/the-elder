# Language support (i18n)

Eleven languages: English (source), Spanish, K'iche', French, Portuguese, German, Danish, Dutch, Japanese, Korean, Simplified Chinese.
Choosing one in the toggle (top-right of every page) translates the interface, and the model is told to answer in it.

## Where things live

| Piece | File |
| --- | --- |
| Language list, server names, validation | `lib/i18n/languages.ts` |
| Catalogs (English is the source of truth) | `lib/i18n/messages/*.ts` |
| Typed translator, plurals, rich text | `lib/i18n/translate.ts` |
| Provider and `useLanguage()` | `lib/i18n/LanguageContext.tsx` |
| Review status of each language | `lib/i18n/reviewStatus.ts` |
| Server-side sentences (silences, limits, crisis) | `lib/i18n/serverText.ts` |
| Language instruction for the model | `lib/i18n/languageDirective.ts` |
| Toggle | `app/components/LanguageToggle.tsx` |
| Tests | `lib/i18n/i18n.test.ts` (in `npm run test:unit`) |
| Wiring guard | `scripts/check-language-wired.mjs` (`npm run check:language-wired`) |

## How a change in language reaches everything

1. The toggle stores the choice (`localStorage`, key `the-elder-locale`), sets `<html lang>`, and loads that catalog on demand.
2. Components read text with `t('key')`; unknown language falls back to English.
3. Every call that makes the model write for the seeker sends `languageName`: `/api/divine`, `/api/threshold`, `/api/elder/marker-offer`, `/api/journal`. The server accepts only the eleven known names (anything else becomes English), so the field cannot carry instructions.
4. Sentences the server writes itself (silences, limits, the crisis messages) come from the same catalogs through `serverText`.
5. Dates, ordinals and plurals follow the language (`lib/i18n/format.ts`, `_one/_other` keys).

Before this work nothing sent `languageName`, so the model never knew the chosen language. `check:language-wired` now fails the build if a client stops sending it or a route stops reading it.

## Review status: read this before shipping to real seekers

Every non-English catalog is a **machine draft**. `reviewStatus.ts` records that, and `ELD-049` in `governance/checklist.yaml` already says the ceremonial register must be checked by a native speaker, not only the accuracy.

- **Safety copy** (the three crisis messages and the safety silence) is sent as the translation, then a separator, then the reviewed English, until a language is `native-reviewed`. A translation error can add confusion; it cannot remove the reviewed message.
- **K'iche'** is the weakest. Only a few short interface words are in K'iche'; the rest is the Spanish text, because Spanish is the shared written language of most K'iche' readers and a fluent Spanish line is safer than K'iche' grammar nobody here can vouch for. A visible bilingual note says so when K'iche' is selected.
- Governed copy (Purpose Statement, figure-continuity pairing copy, welfare-adjacent notices) is translated too. The English is unchanged and still single-sourced. The translations have **not** gone through the sign-off the English did (`docs/figure-continuity-copy-review.md`).

### Recording a native review

In `lib/i18n/reviewStatus.ts` set, for that language only:

```ts
es: { status: 'native-reviewed', reviewedBy: 'Full Name', reviewedOn: '2026-11-02' },
```

A test fails if a language is marked reviewed without a named person and date. Marking it reviewed drops the English tail from that language's safety copy and hides its draft note. Do not flip it without a named human.

## Adding or changing text

1. Add the key to `messages/en.ts` (`as const`; placeholders are `{name}`; counted text uses `_one` / `_other`).
2. `npx tsc --noEmit` now fails in every other catalog until each has the key.
3. `npx tsx lib/i18n/i18n.test.ts` checks key parity, identical placeholders, paragraph breaks, and that long strings were actually translated.
4. English that the server sends is mirrored in the catalog; the test fails if the two drift.

## Red team / blue team ledger

| # | Attack | Defence |
| --- | --- | --- |
| R1 | A missing translation hides behind the English fallback | Other catalogs are typed `Record<MessageKey,string>`; parity test in both directions |
| R2 | A placeholder is dropped or invented | Placeholder names typed; parity test |
| R3 | A string is pasted untranslated and passes parity | Test rejects long strings identical to English |
| R4 | The language name carries a prompt injection | Closed set of eleven names; anything else becomes English; test with hostile inputs |
| R5 | K'iche' apostrophes differ (straight vs curly) and fall to English | One shared module; test accepts both |

| R7 | A catalog fails to load | Stay in the current language; never hold the screen |
| R8 | Rapid toggling races | Latest request wins |
| R9 | Language changed in another tab | Storage listener |

| R11 | Steelman against: a machine-drafted crisis message could be worse than English | Reviewed English appended until native review; disclosed |

## Known gaps (not done, on purpose or for lack of a reviewer)

- **Crisis resources are US-only** (988, 741741) in every language. Translating the words does not give a seeker in Japan or Germany a number that works. Needs a clinical and legal decision per country.
- **Welfare judges, the English keyword routing in `mythRoutingIndex`, and the register guards read English.** A seeker writing in another language gets the model's understanding, not the keyword floor.
- **Archetype cards and diagnostic questions** (`lib/archetypes.ts`, 61 cards) are still English. The model's replies and the surrounding interface are translated.
- **Bearer-authored text** (the psychopomp threshold-letter phrases, `timeMeaning`) stays in the original English inside the translated interface. It was written by a person for a purpose; machine-translating it needs your decision.
- **Journal synthesis** is cached without a language. For non-English seekers it is not read from or written to that cache; a six-hour in-memory cache stands in, so it can regenerate after a restart.
- **Static metadata, share/OG images, letter emails, and the operator AltarRecord** are English.
- **Figure-continuity translations** are drafts without the English sign-off.
- `npm run lint` is broken independent of this work (no `eslint.config.*`).
